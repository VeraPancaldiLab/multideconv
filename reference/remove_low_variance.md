# Remove low variance deconvolution features

Remove low variance deconvolution features

## Usage

``` r
remove_low_variance(data, plot = FALSE)
```

## Arguments

- data:

  Deconvolution features

- plot:

  Whether to save or not the plot of variance distribution in the
  Results/ directory.

## Value

A list containing

- Deconvolution matrix after removal of low variance.

- Discarded low variance features.
